# 变更记录目录

本目录只保存**代码类修改**的 Markdown 记录（C/头文件、Makefile、会参与编译或板上运行的脚本等）。

- **写文档不需要**在此建记录（如仅改 `AGENTS.md` / `README.md` / 本目录说明）
- 时区：一律使用 **UTC+8（北京时间）**
- 文件命名：`YYYY-MM-DD-简短中文标题.md`（同一天多条可加序号后缀，如 `-02`）
- 每条记录须按 [`_TEMPLATE.md`](_TEMPLATE.md) 填写完整章节
- 涉及源码处使用**仓库内相对路径**链接，便于在 GitHub / IDE 中点击跳转
